# The fake budget

All building and testing happens against a made-up budget on the NUC, never the real one. *Claude Code fills in the details as F0-1 builds it.*

## What it must have

Enough to exercise every screen, all invented and generated by a seed script (same output every run):

- **Accounts:** checking, savings, two credit cards, a loan, and one account that belongs to "someone else" (to test leaving accounts out of totals). Include an off-budget account if Actual supports it.
- **Categories:** a normal household set in groups (housing, utilities, food, transport, subscriptions, fun, savings goals).
- **History:** 12 months of transactions: paychecks every two weeks, rent or mortgage, utilities, groceries, gas, dining, subscriptions on fixed days, a price increase on one subscription, transfers between accounts.
- **Budgets:** amounts for every month, some categories over, some under.
- **Unusual charges to find:** a duplicate charge, a large one-off at a usual merchant, a new merchant with a big first charge.
- **Schedules:** a few, if Actual's API supports creating them in an import.

## Where it runs

An Actual server on the NUC, reachable only from the NUC itself (localhost), with its own throwaway password kept out of the repo.
