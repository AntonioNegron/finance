# Antonio does the one-time install; Claude Code runs the updates

*2026-11-17 · Antonio*

**Decision:**
- **One-time install (Antonio):** the few steps that need `sudo` or a password: one install command, then typing the passwords at a hidden prompt. Only he can do this part, because it holds the secrets.
- **Every update after that (Claude Code):** Claude Code marks a version ready by moving the repo's `deploy` branch. The OptiPlex checks that branch every few minutes on its own (read-only key), builds the new version and restarts the app. Claude Code sees only `/healthz`: `ok` or `error` and the running commit.

*Refined the same evening (Claude):* the first version said a fixed `optiplex finance-deploy` command. Having the OptiPlex pull the update instead gives the same result with nothing new unlocked for Claude Code's OptiPlex account, and the updater can't change the app's network, folders or secrets: those change only when Antonio reruns the install.

**Why:** Antonio asked to do it himself only if it's a few steps, and to leave anything with many steps or configuration to Claude Code. The install is a few steps; updates repeat for as long as the app exists.
