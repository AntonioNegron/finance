# Claude Code never reads Antonio's financial or security information

*2026-11-17 · Antonio*

**Decision (his words, lightly edited):** only Antonio can access anything related to the information Actual provides. Claude Code is strictly prohibited from reading any of his financial or security information. Everything else Claude Code can build: the API setup and turning it into something more intuitive on the phone that makes it easier for him to see what he needs to track his finances.

If Claude Code needs information (for example numbers to help with budgeting), it must be very explicit and ask permission first, so he knows that it will happen and what it will see. Something in between that filters the information down to what's needed is an acceptable way to do it.

**How:** the rule is enforced by the OptiPlex (separate owner, closed logs, no outbound network, the app's own login), not only by instructions. See [plan.md](../plan.md#how-the-privacy-rule-is-enforced) and [../../CLAUDE.md](../../CLAUDE.md). Asking for numbers uses the [permission request](../README.md#asking-for-numbers).

**Why:** it's his and his household's financial data.
