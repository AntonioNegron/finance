# Actual goes to 26.11.0, pinned, and the app moves in step with it

*2026-11-17 · Antonio*

**Decision:** Antonio's Actual (client and server both v26.4.0, Settings offering v26.11.0) is updated to **26.11.0**, the version F0-1 built and tested against. Its compose file names that exact version instead of `latest`, so Actual only changes when he decides. From then on, Actual and the app's `@actual-app/api` are upgraded together: Claude Code first updates and tests the app on the fake budget, then Antonio updates Actual.

**Why:** the API package carries Actual's own budget engine, and Actual's docs don't promise that different versions work together ([F0-1 report](../tasks/F0-1.report.md#matching-the-api-to-the-server-version)). Actual's Docker docs advise keeping backups when using `latest`. Sources: https://actualbudget.org/docs/install/docker (image tags), Actual release notes (`Docker Tag: <version>`).
